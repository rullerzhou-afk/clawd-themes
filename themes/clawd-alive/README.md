# Clawd Alive

A [Clawd on Desk](https://github.com/rullerzhou-afk/clawd-on-desk) theme that gives Clawd more personality, using only art.

![Clawd Alive preview](https://raw.githubusercontent.com/rullerzhou-afk/clawd-alive-theme/45638cacfca0ef81cc3a31e8339c1d4a1176feaa/preview.webp)

- **Author**: Allan Oliveira Miraballes
- **Version**: 1.0.0
- **Theme ID**: `clawd-alive`
- **Source**: <https://github.com/AllanOliveiraM/clawd-alive-theme>

## What's different from the default Clawd

- **Idle:** 13 extra moments join the random pool: content, curious, tired and shy looks, a morning stretch, coffee, a late-night yawn, stretching after work, a ball, a yo-yo, a paper plane, sitting on the edge and a fake nap.
- **Sleep:** a dreamy sleep with a twitching leg.
- **Work:** the more agents run, the more chaotic it gets, from one agent with a coffee up to six or more in full chaos. With one to three agents, the original animations stay in the mix.
- **Subagents:** laptops at three, and chaos at four or more.
- **Reactions:** a grumpy answer when annoyed, and a "Boo!" among the rapid-click reactions.
- **Free Roam:** a bouncy walk.
- **Original animations:** a reworked error animation, and a crab walk that starts and stops without jumping.

## Install

Copy this folder into your Clawd on Desk themes folder as `clawd-alive`, then pick the theme under **Settings... → Theme**.

| System | Themes folder |
| --- | --- |
| Windows | `%APPDATA%/clawd-on-desk/themes/` |
| macOS | `~/Library/Application Support/clawd-on-desk/themes/` |
| Linux | `~/.config/clawd-on-desk/themes/` |

## Known limitations

- The moments are picked at random, without mood or time of day. A late-night yawn can show up at noon.
- Every sleep has the twitching leg.
- Both the confirm and completion sounds use the built-in sounds from Clawd on Desk.
- Tested on Ubuntu with GNOME under XWayland only. It has not been tried on Windows or macOS.

## The full Clawd Alive

A theme can only carry art, so this one has no mood, petting, mischief or fetch. Those live in a personal experiment on my fork of Clawd on Desk, where the pet reacts to you and does things on its own. There you can see it in [this video and write-up](https://github.com/rullerzhou-afk/clawd-on-desk/discussions/1334), and the code is on the [`feat/clawd-alive`](https://github.com/AllanOliveiraM/clawd-on-desk/tree/feat/clawd-alive) branch.

It's built for my own use: there are no releases, you'd have to run it from source, and I've only tried it on Ubuntu under XWayland. For everyday use, this theme is the simple way to enjoy the art.
