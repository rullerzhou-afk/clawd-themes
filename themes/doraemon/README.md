# Doraemon（机器猫）

Doraemon 是 Clawd 的外置社区主题：一只功能齐全的蓝胖子桌面伙伴——眼球会跟随光标，会在桌面上自由漫游，工作时有敲键盘、变戏法、盖房子等多会话状态，待机时会掏出铜锣烧和四次元口袋道具，还有完整的打哈欠、打盹、瘫倒、入睡、醒来睡眠周期，以及点击与拖拽反应。

## 版本

- 主题版本：`1.0.0`
- 最低 Clawd 版本：`1.2.0`
- 动画资源：22 个自包含 SVG（纯 CSS 动画，无脚本）
- 来源：社区贡献，作者 [RyanChenJJH](https://github.com/RyanChenJJH)
