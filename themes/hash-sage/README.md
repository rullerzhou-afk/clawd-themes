# Hash Sage（哈希仙人）

Hash Sage 是 Clawd 的可选官方主题：一位乘云而行的像素仙人，包含普通状态、多会话工作状态、完整睡眠序列、点击与拖拽反应、自由漫游以及 Mini 模式动画。

## 版本

- 主题版本：`1.0.0`
- 最低 Clawd 版本：`1.0.0`
- 动画资源：32 个 APNG
- 来源：`clawd-on-desk` 提交 `4cf6876d0c71f59bd2c647e43b20a85cde24146b`

## 已知说明

基础 `idle` 动画仍使用已确认的样片 E（原片节奏 `0.67×`）。这项状态不会因为主题包标记为 `1.0.0` 而被描述为最终美术定稿。
