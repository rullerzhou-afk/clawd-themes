# Whale-chan（鲸鱼娘）

Whale-chan 是 Clawd 的可选官方主题：一位摇着鲸尾的蓝发桌面伙伴，陪你工作、漫游与入梦。

## 版本

- 主题版本：`1.0.1`
- 最低 Clawd 版本：`1.2.0`
- 动画资源：34 个 WebP 动画（2 倍清晰度）
- 来源：`clawd-on-desk` 提交 `14ec67947f63ef9a5832041b3882cf1b4f235435`

## 更新记录

- `1.0.1`：全部动画改为 2 倍清晰度的 WebP，在 Retina 等高分屏上或把桌宠调大时不再发糊；画面、位置和时长与 1.0.0 相同。已安装 1.0.0 的用户，在 Clawd「设置 → 主题」里删除鲸鱼娘后重新下载即可。
- `1.0.0`：首个版本。

## 已知说明

迷你模式的探身保持与睡着探身，以及 `idleVisualOptions` 待机形象选项，依赖 Clawd `1.2.0` 新增的能力。
